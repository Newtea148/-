# 时间音乐 Time Music

> 把歌单当成闹钟——按时间段自动播放对应歌单的本地音乐播放器

一款 Windows 本地音乐播放器，核心特色是「时间歌单」：你可以创建多个歌单，给每个歌单设置一个播放时间段（例如早上 06:00–11:30 播放歌单1、午后 11:30–16:00 播放歌单2），时间一到，软件自动切换播放对应的歌单。

完全本地、离线运行：读取电脑里的音频文件，不联网、不登录、不依赖任何云服务，断网也能完整使用。

## 功能特性

### 时间歌单（核心）
- 左侧可创建任意数量的时间歌单，每个歌单绑定一个本地音乐文件夹
- 歌单名称自定义，如「早安」「午后」「夜晚」，随时可重命名
- 每个歌单独立设置播放时间段：开始时间 + 结束时间，最小单位为分钟，最大单位为小时
- 智能切换：到达歌单结束时间后，若当前歌曲尚未播完，会先播完这一首，再自动切换到下一个时间段的歌单，绝不中途打断

### 播放模式
- 顺序播放：按歌单内列表顺序循环播放
- 随机播放（洗牌不重复）：在歌单内随机选曲，每首播完即从候选池排除，不再重复；直到歌单结束或全部曲目播完，候选池重置后再次随机

### 格式与歌词
- 全格式支持：MP3 / FLAC / WAV / AAC / M4A / OGG / APE / WMA / ALAC 等常见格式
- 本地歌词：读取音乐同目录的 `.lrc` 歌词文件，随播放滚动高亮当前句；无歌词时自动放大显示音乐名

### 简洁界面
- 左侧：闹钟式时间歌单列表，从上到下排列，每项带【打开根目录】【设置时间】按钮
- 中间：垂直进度条（上端当前播放时间、下端整曲总时长），兼作左右分栏的分界线
- 右侧：上方为歌名（两侧是上一首 / 下一首三角按钮），下方为歌词区
- 设置面板：UI 主题色、10 段音乐均衡器、开机自动启动（默认关闭）、更改音乐读取目录、桌面歌词（默认关闭）

## 快速上手

1. 新建时间歌单 → 输入自定义名称（如「早安」）
2. 点击该歌单右侧的【时间】→ 设置播放时间段（如 06:00–11:30）
3. 点击【根目录】→ 选择这个歌单对应的音乐文件夹
4. 在右侧选择播放模式：顺序播放 或 随机播放
5. 到点后软件自动播放对应歌单；时段结束先播完当前曲，再自动切换下一个歌单
